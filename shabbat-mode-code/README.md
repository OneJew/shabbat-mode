# מצב שבת

תוכנת ווינדוס חינמית שמכבה את המחשב לבד לפני שבת וחג, לפי העיר והמנהג.

## שימוש
1. מפעילים את `ShabbatMode.exe`. עמוד ההגדרות נפתח בדפדפן.
2. בוחרים עיר, דקות הדלקת נרות וכמה זמן לפני לפעול.
3. מסמנים "להפעיל עם ווינדוס" ושומרים.

לפני הפעולה מופיעות התראות 30, 10 ודקה אחת מראש, ואפשר לבטל. מחשב שנדלק בזמן הזה מקבל התראה ו-3 דקות.

## אין אחריות
התוכנה ניתנת בחינם ו"כמות שהיא", בלי אחריות מכל סוג. אין אחריות על שום נזק, חלילה, ישיר או עקיף, כולל אובדן מידע, כיבוי בזמן לא רצוי, אי-כיבוי או טעות בזמנים. התוכנה אינה פוסקת הלכה ואינה תחליף ללוח זמנים מוסמך או לשאלת רב.

## חשוב לדעת
- הזמנים לא מתחשבים בגובה ובהרים. יש להשוות ללוח ולהשאיר מרווח.
- לוח החגים הוא של ארץ ישראל.
- המחשב צריך להיות דלוק והתוכנה פועלת.
- הגדרות נשמרות ב-`%AppData%\ShabbatMode`.
